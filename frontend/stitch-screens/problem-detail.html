Optimal Pathfinding

Medium Time Limit: 2.0s Memory Limit: 256MB

Given a grid of size N x M representing a labyrinth, find the length of the shortest path from the top-left corner (0, 0) to the bottom-right corner (N-1, M-1).

The grid consists of 0s (passable) and 1s (impassable obstacles). You can move up, down, left, or right. If no path exists, return -1.

Example 1:

Input:
grid = [[0,0,0],[1,1,0],[1,1,0]]
Output:
4

Constraints:

  • 1 <= N, M <= 100
  • grid[i][j] is 0 or 1
  • grid[0][0] == 0 and grid[N-1][M-1] == 0
